# DEMO-GATE：稳态导热 → 线弹性翘曲

在仓库根目录运行（需要带 MFEM、MPI、HDF5 数值后端的构建）：

```sh
chipcae-solve --case examples/demo_gate/case.json --profile examples/demo_gate/profile.json --out out/demo_gate
```

本例使用单 rank CPU、四角各斜切 2 mm 的 20 × 20 mm 外轮廓，
进行单步稳态导热并将温度传给线弹性求解，输出 VTKHDF 温度、位移及翘曲。
全部材料与热载荷数值均为示意值，不是实测或供应商为本项目提供的数据。
芯片层总功率 P = 10 W 是工程选择，不是文献值；底面定温为 298.15 K，
顶面对流系数为 10 W/(m²·K)，环境温度为 298.15 K。
受当前热源接口限制，功率均布在整个芯片层（包括芯片和底填），不只在芯片区域。
斜切面和侧面使用绝热自然边界。外形已斜切，因此 S_cc 不定义。

按热载荷说明的一维量级估算，面积 A = 3.92e-4 m²，顶面对流热阻
1/(hA) 约为 255 K/W，向下一路热阻约为 0.8 K/W，所以估算有 99% 以上
热量从底面流走。这是一维估算，不是本算例的实测结果，也不是精度验收判据；
本例用于演示耦合求解，不应解释为实际封装散热分析。

材料卡的 conductivity 旁保留公开引用。导热系数使用常数：有机基板采用
等效厚度方向标量值，不能反映真实面内铜层扩热；焊球等效层铺满整层并使用
SAC305 体材料导热系数，会高估该层导热。密度仍为母版占位值，稳态导热不使用它。
因此一维估算不能替代三维温度场与实际封装的验证。

本演示输入的扩展元数据也属于冻结的样例契约，由 `demogate_inputs` 校验：
每张材料卡必须包含字符串 `x-conductivity-source`，说明相邻 `conductivity`
的公开来源；四张卡的引用句全文（含链接、标点）以本目录 `materials.json`
为准，测试中的 `sources` 表保存相同文本。顶层 `x-note` 必须逐字保留
`schema/examples/fcbga_demo.materials.json` 母版的说明。
这些是本样例的文档与来源追溯字段，不参与求解，也不要求其他材料库采用；
材料库 schema 的顶层 `^x-` 扩展点允许 `x-note`，本样例在此明确其含义与保留规则。
