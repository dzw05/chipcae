# ADR-0004：自研耦合层与 preCICE 适配器

- 状态：已接受
- 日期：2026-11-16
- 编号：D4

## 背景

产品需要在有限元热应力、后续的流体传热以及更远期的粒子方法之间交换场。完全绑定单一外部耦合库会限制内部求解器的迭代速度；完全自研又不利于以后与第三方求解器互操作。Zhiwei 已在原则上同意：自研耦合层，同时提供 preCICE 适配器。

## 决策

- 内部求解器之间的场交换走本仓库的 `coupling/` 耦合器与场映射。
- preCICE 适配器在 v2 交付。
- 对外提供 preCICE 适配器，用于与外部求解器联算。
- 两套路径共享场映射接口，避免为同一种插值维护两套实现。

## 后果

- 需要尽早冻结耦合接口和误差度量，并把映射正确性纳入测试。
- preCICE 本身在启用适配器之前不是必选依赖。
