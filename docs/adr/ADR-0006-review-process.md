# ADR-0006：AI 交叉评审与 owner 把关

- 状态：已接受
- 日期：2026-11-16

## 背景

需要在自动化开发效率与关键架构决策之间建立明确责任。决策来源：owner 对审查模式的决定。

## 决策

采用 AI 交叉评审与自动验收测试；编码代理不得评审自己的代码。Zhiwei（owner）把关接口冻结与 ADR、数值方法选型、Ansys 对比基准与 golden data、里程碑与发布、新增依赖或许可证变更。

- main 不启用分支保护；唯一的硬门禁是 CI 汇总检查 `ci-ok`。CODEOWNERS 只用于提醒和路由，不强制审批。
- 关键节点（见上）由 PR 作者在描述中标注，Zhiwei 事后签字确认。

## 后果

普通实现由交叉评审与 CI 验收，关键节点交由 owner 决定。
