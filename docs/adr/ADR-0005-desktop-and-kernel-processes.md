# ADR-0005：桌面端与求解内核分进程

- 状态：已接受
- 日期：2026-11-16
- 编号：D5

## 背景

桌面端使用 Qt6 与 VTK，求解内核是 C++ 的 MPI 程序，二者的生命周期、依赖和故障模式都不同。若放在同一进程里，界面崩溃或重绘阻塞会直接影响长时间计算，内核的并行依赖也会拖累界面发行。Zhiwei 已在原则上同意分进程。

## 决策

- `gui/` 只负责建模、提交作业和可视化，不链接求解器实现。
- `kernel/` 是求解进程入口，由 `jobmgr/` 拉起并监控。
- `preview/` 是轻量预览子进程，避免网格或结果预览阻塞界面主进程。
- 进程间协议放在 `protocol/`，包名为 `chipcae`，由架构组维护；错误码表见 `protocol/errors.yaml`。

## 后果

- 改协议时需要同时更新两端，这是选择单一大仓库的原因之一。
- 需要约定作业状态、日志和结果清单的稳定格式，并在集成测试中覆盖。
